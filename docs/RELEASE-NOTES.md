# FlipAi v0.46.83

Microsoft Copilot Chat and Muse answer again, and Gemini Chat stops colliding with itself.

- **A JavaScript syntax error in the Copilot and Muse page drivers is fixed.** v0.46.80 added a stability escape to every driver so a stale Stop control could not hold a finished answer. In four drivers it was separated from the statement before it; in Copilot and Muse it was appended directly after a `}`, which is `SyntaxError: Unexpected token 'if'`. Both scripts failed to parse, so neither provider could answer a single message — the browser never ran a line of the driver. A syntax error in an injected script is invisible to a Go test suite: it compiles, it ships, and it fails only in the browser.
- **Every page driver is now parsed before it can ship.** A new test runs each injected script through `node --check`. It fails against the shipped v0.46.82 drivers, naming both broken providers.
- **A page-script failure now says what failed.** Every provider reported a page exception as the bare sentence "the *provider* page script failed" and discarded the exception, so a syntax error in FlipAi's own driver looked exactly like a site redesign, a signed-out session or a changed selector. The exception class, message and line are now carried into the Activity log — never to the sender.
- **`Overlapped I/O operation is in progress` is fixed properly.** v0.46.81 serialized DevTools calls, but released the channel when FlipAi stopped waiting — while the call was still live inside WebView2, which has no way to cancel one. The next call was then issued on top of it and rejected, which is why Gemini Chat still failed instantly. The channel is now held until the call actually completes, bounded so a callback that never fires cannot reserve it for the life of the process.

Validation: publication is gated by the release workflow's full Linux test suite, real-browser call-flow tests, Windows tests, vet, race tests, Windows build, Google Voice integration, installer install/uninstall smoke tests, Microsoft Defender checks, provenance, checksum, and CycloneDX SBOM generation.
