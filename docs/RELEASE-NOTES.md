# FlipAi v0.46.84

Gemini Chat, Microsoft Copilot Chat and Muse.

- **`Overlapped I/O operation is in progress` was never a collision.** A COM call reports success in the HRESULT it returns; the third value from a Go syscall is the thread's *last error*, which is meaningful only when the call actually failed. FlipAi's WebView2 binding read that last error as the result, so a DevTools call WebView2 had already accepted was reported as refused whenever unrelated async I/O had left `ERROR_IO_PENDING` on the UI thread — and its completion handler was dropped, so the reply could never arrive either. Gemini Chat failed instantly on every turn because of it. The call is now judged by its HRESULT. This also explains why serializing DevTools calls in v0.46.81 and v0.46.83 never helped: nothing was colliding.
- **Microsoft Copilot's prompt is sent even when no Send button appears.** The driver typed the prompt, waited eight seconds for a control matching "send", and abandoned the turn with the prompt sitting in the box. It now submits with Enter, the way a person does.
- **Muse's answer is found even when the page names nothing FlipAi recognizes.** Muse answered, its answer was on screen, and every selector missed it, so the turn reported that the model had stopped without producing anything. Both drivers now fall back to reading the conversation structurally, and identify a new answer by its text rather than by its position in a list that changes while the page renders.
- **The drivers are now driven in a real browser before they ship.** A new harness runs each turn script against a chat page that uses none of the names they look for — anonymous divs, no author roles, no `data-testid`, no `<main>` — in one variant with no send button at all. Against the v0.46.83 drivers it reproduces both reported failures exactly, and it passes with these fixes.

Validation: publication is gated by the release workflow's full Linux test suite, real-browser call-flow tests, Windows tests, vet, race tests, Windows build, Google Voice integration, installer install/uninstall smoke tests, Microsoft Defender checks, provenance, checksum, and CycloneDX SBOM generation.
