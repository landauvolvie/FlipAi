# FlipAi v0.46.95

Improvements only. ChatGPT is working and its page, composer and turn logic are untouched — the single line changed in that driver is inside how a reply's text is read.

- **News cards and source pills are no longer part of the answer.** When ChatGPT answers a question about the news it puts a pill after each claim — "AP News +1", "Reuters +1" — and a row of picture cards with headlines under the answer. All of it was arriving in the text message, in the middle of what the model wrote. A card is a picture with a headline and a link on it; a pill is a whole element whose text is a source followed by "+2". Neither is a sentence. Both are recognized by shape rather than by a class name, so a linked phrase inside a sentence still survives, and the model's own closing line still travels. Microsoft Copilot and Muse get the same treatment.
- **Muse's step rows are no longer mistaken for the answer.** "Find Orlando trip dates Checked memories and Hertz emails, no date found 1:13 pm" is the page narrating, not the reply — the real answer, the Hertz pickup date, was written seconds later. A row that ends with the time it happened at and no sentence punctuation is narration. The answer is given every chance first, and only near the end of a turn's budget will FlipAi fall back to such a row, so this can delay a reply but never lose one. Microsoft Copilot has the same shape and gets the same rule.
- The driver harness grew to forty-three scenarios. Two of them are built from exactly what reached the phone: the news answer with its pills and card row, and the step row followed by the real answer. Both fail against the previous drivers.

Validation: publication is gated by the release workflow's full Linux test suite, real-browser call-flow tests, Windows tests, vet, race tests, Windows build, Google Voice integration, installer install/uninstall smoke tests, Microsoft Defender checks, provenance, checksum, and CycloneDX SBOM generation.
