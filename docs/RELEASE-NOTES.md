# FlipAi v0.46.88

Three agents that could not deliver a message now can.

- **Gemini never sent anything.** "FlipAi filled the Gemini prompt box but the Send button never became ready" — Gemini was the last driver whose only way to submit was a button it could name by selector, so a renamed or disabled control left the prompt typed and abandoned. Gemini, Claude and Grok now fall back to the composer's own form submit and then the Enter key, the way ChatGPT, Copilot and Muse already did. A test fails the build if any driver can still give up there.
- **Microsoft Copilot's answers arrived with words missing.** "AI regulation", "climate rules" and "immigration lawsuits" were gone from the middle of sentences. Removing the source cards had been done by deleting every element the page labelled a citation, source, reference or card — and inside a sentence, those labels are on the links themselves. Only block-level containers count as page furniture now: an inline link keeps its words, a bare superscript marker is still dropped, and the cards still go. The same applies to ChatGPT and Muse.
- **ChatGPT failed with `Runtime.evaluate failed in the WebView page (0x80070057)`, and ChatGPT never saw the message.** Signed in is not the same as ready: the experience switch can leave the page on a shell with no composer, and the page driver cannot run there at all. The turn now waits for a prompt box before running the driver and lands on the canonical root if there is none. That one failure proves nothing was typed, so it is retried once on a recovered page — only while enough of the request budget is left for the turn to still finish.
- **ChatGPT sent one paragraph instead of the message.** A linked sentence in its own paragraph made the reply stop being a leaf block, and only that paragraph travelled while the written answer above it was dropped. A match is now lifted back to the whole message.
- The driver harness grew from twenty-one scenarios to twenty-four, covering all six browser agents: Gemini, Claude and Grok are now driven against a page with a composer and no send control at all, and the source-card page renders a sentence with linked phrases in it, asserting the phrases survive while the cards do not.

Validation: publication is gated by the release workflow's full Linux test suite, real-browser call-flow tests, Windows tests, vet, race tests, Windows build, Google Voice integration, installer install/uninstall smoke tests, Microsoft Defender checks, provenance, checksum, and CycloneDX SBOM generation.
