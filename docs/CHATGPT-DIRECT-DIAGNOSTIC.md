# ChatGPT Direct Diagnostic

FlipAi v0.46.8 uses one comprehensive, non-invasive Windows architecture survey to decide the next regular-ChatGPT integration step.

The diagnostic reports:
- owned localhost and Chromium debugging transports;
- ChatGPT process/child-process topology;
- WebView2, Electron/Chromium and WinUI runtime module signals;
- AppX package identity, application entries, extensions, AppServices and URL activation protocols;
- window class names;
- active remote address/port metadata and cached ChatGPT/OpenAI DNS names;
- app-specific protocol-marker sources separated from bundled browser/Playwright/Codex/runtime noise;
- a final Direct-backend assessment.

The diagnostic does not use UI Automation, move focus, type, launch a hidden ChatGPT browser, read cookies/tokens/browser storage, inspect process memory, read full command lines, capture packet contents, or invoke registered protocols.

A result is evidence only. SMS routing must remain disabled until FlipAi has proven an actually callable ChatGPT-owned request transport.
