## Virtual Audio Driver

FlipAi's optional **Install free audio bridge** feature downloads the pinned signed release of [VirtualDrivers/Virtual-Audio-Driver](https://github.com/VirtualDrivers/Virtual-Audio-Driver) from its official GitHub release page and creates two virtual audio device instances for the phone-to-desktop voice bridge.

## nefcon

FlipAi's optional audio-bridge installer downloads a pinned release of Nefarius `nefcon` from its official GitHub release and verifies the archive SHA-256 before using it to create/bind the two root-enumerated virtual audio device instances. FlipAi does not modify Windows test-signing, Secure Boot, or certificate trust stores.
